# veydr-web

Landing page for [Veydr](https://github.com/alexnakagama/veydr). Astro + Tailwind CSS v4, built as static HTML and deployed on Vercel.

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
npm run check    # type check
```

The project drive is exFAT, which can't hold symlinks, so `.npmrc` sets `bin-links=false` and the npm scripts call Astro directly.

## How release data gets in

`src/lib/release.ts` reads the latest release from the GitHub API **at build time**: tag, date, `.deb`/AppImage URLs and sizes, and the hashes in `SHA256SUMS`. If GitHub can't be reached, the build uses the last known release instead of failing. Set `GITHUB_TOKEN` in Vercel to avoid the anonymous rate limit (optional).

### Rebuild on every Veydr release

1. Vercel → Project → Settings → Git → **Deploy Hooks**: create a hook and copy its URL.
2. In the `veydr` repo, add it as the secret `VERCEL_DEPLOY_HOOK` and add this workflow:

```yaml
# .github/workflows/website.yml
name: Rebuild website
on:
  release:
    types: [published]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - run: curl -fsS -X POST "${{ secrets.VERCEL_DEPLOY_HOOK }}"
```

## Assets

- `src/assets/screenshots/` and `src/assets/brand/` are copied from the `veydr` repo (`docs/screenshots/`, `assets/brand/`).
- `public/og.png` is generated by `node scripts/make-og.mjs`.
- Design tokens in `src/styles/global.css` mirror the app's `src/renderer/src/styles.css`.

The site URL defaults to `https://veydr.vercel.app`. Set `SITE_URL` in Vercel if the project gets a different name.
